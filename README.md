# Your agents, working in your business

Start in T3 Code with your ChatGPT plan connected. Send:

> Read https://github.com/agentic-u/start and set me up.

Your agent sets up a business folder, opens it as a T3 project and helps you understand what to work on first. Your words and work stay on your computer. You can close the app and come back to the same folder.

**For the agent:** read [BOOTSTRAP.md](BOOTSTRAP.md) in full and carry out that session. The person has asked you to set them up. Use this repository's current files; record the commit you followed. A new thread should use the saved local checkpoint rather than start over.

This is an early Mac-first release under test. The setup includes local Git, Codex defaults, T3 project configuration and OpenCode Browse. Browser extension installation/pairing and account sign-ins can need the person's involvement; continue independent business work while a connection is waiting. Installing an extension is not proof that browser control works.

Nothing in this session sends messages, spends money or publishes the person's business files. This repository is public; their business folder is separate and has no remote unless they explicitly choose one.
