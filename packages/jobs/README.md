# Local artifact review jobs

`@agentic-u/jobs` is a caller-driven Node 26 SQLite host for an XState pure transition model. It reviews actual local Markdown bytes against an explicit standard: exact heading names and literal evidence strings. SHA-256 and byte length identify the reviewed artifact. This adapter checks those predicates only; it does not supply model judgment, assess competence, or infer principal acceptance.

Call `admitCommand(unknown)` at the transport boundary, then `command(databasePath, checkedCommand, artifactDirectory)`. Use `show(path,id)` from a fresh process to inspect a job. `start` requires an existing progress attempt, artifact path and progress database path; omit the standard with `standard:null` to request missing input. On first start, artifact and progress paths become absolute; the original request is retained for key replay. Library callers may supply an explicit artifact directory; otherwise the initial caller's cwd anchors it. Resume never reinterprets a relative artifact against a new cwd. `provide_input` admits the standard. `resume` claims ready work, then `run(path,id,{authorizeDecision})` performs it. A completed review is `review_ready`; the next `resume` moves it to `waiting_approval`. A `decide` command supplies the principal's actual decision and exact review digest. `run` records it in the existing progress owner after calling the composition's fresh `authorizeDecision(job)` Effect immediately before dispatch and checking the artifact digest again. The callback is mandatory and returns typed `ApprovalDenied` failures; denial preserves the pending intent for an explicitly approved continuation. A principal string is not authority.

The supported registry lives at `@agentic-u/jobs/operations`: `jobOperations` exports `job_start`, `job_show`, `job_input`, `job_resume`, `job_retry`, `job_cancel`, `job_decide` and `job_continue`. Inject `JobsStorage` with host-selected `databasePath`, `progressPath` and `houseDirectory`. Transport inputs cannot choose either database. The registry anchors relative artifact references to that house. Donor `Approval` gates both decision and continuation at entry, and the dispatcher calls the current service again with the full exact job under `job_decision_dispatch`. Supply `Approval.denyAll` by default. Ungated resume cannot dispatch any pending decision. `afterDecisionDispatch` is an optional host instrumentation seam used by the SIGKILL qualification, never a transport input.

Every command has a globally unique stable `key`. Commands after start also carry the observed `revision`. The same key and full content returns the exact saved response, even if later work has advanced. Different content under a key conflicts; a stale revision conflicts. `run` deliberately has no command key: it resumes the persisted, idempotent step. It never runs automatically at import or on `show`.

SQLite immediate transactions save job transitions and command replies together, with FULL synchronous durability. No transaction spans filesystem/progress IO. Unknown/unsupported persisted state is rejected without replacement. Storage and busy errors remain typed failures. There is no migration or hidden fallback. The host selects private `.agenticu/jobs.sqlite` and progress locations. Only the command write boundary creates its parent directory; show opens read-only and neither initializes nor executes jobs. This package creates no lock or alternate learning journal.

Reviews record deterministic artifact/check receipts through `@agentic-u/progress`. Decisions save their full intent before dispatch. After a lost acknowledgment, `run` reads progress, compares the full receipt and completes from that readback; absence after a successful local read permits the same-key idempotent record. Failed readback leaves `effect_unknown`. `resume` explicitly reclaims that state. No generic remote adapter or exactly-once remote effect claim exists.

`cancel` prevents dispatch before a running claim. After the decision claim it records `cancelRequested`; reconciliation can still report the already-claimed decision's actual result. It does not reverse an effect. `retry` is legal only for a failed review step whose progress receipts are idempotent. Changed artifact bytes invalidate approval; start a new job to review them. `completed`, `rejected`, `cancelled`, and `failed_terminal` are terminal.

`pnpm --filter @agentic-u/jobs build` then `pnpm --filter @agentic-u/jobs test` runs five `@effect/vitest` qualification groups using real temporary artifacts and fresh child processes. They cover exact predicates, missing input, fresh-process/cwd resume, key replay, revision races, safe retry, changed bytes, rejection, cancellation, corrupt-state preservation and progress readback. The supported `job_decide` operation SIGKILLs after actual decision dispatch before job commit; a fresh process uses gated `job_continue` and proves one receipt. Approval default denial and revocation between entry and dispatch produce zero decision receipts. Test principals and approvals are synthetic fixtures, not real acceptance. Full source/test oxlint and oxfmt checks also pass.
