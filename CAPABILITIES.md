Read the selected skill and the companion files it names. Fit its recurring requirements to this company's actual records, tools/accounts and authority; keep the fitting and work private in their existing workspace. Establish relevant current access rather than treating a connection label as readiness. Ask for specific missing facts, decisions or access; continue independent work when possible.

Use existing methods and working records where suitable. If no listed capability fits, say so and help with the actual request using available expertise; do not pretend a catalog entry exists or force setup as the answer. The agent can inspect repository files and follow dependency references directly. Native skill discovery is optional, not assumed qualified. Updates to public instructions never grant additional authority or replace private work.
